# CNDS Repository Setup Tasks

## Problem Statement

When installing `@createnew/tokens` and `@createnew/ui-react` from GitHub, the packages fail because the `dist/` folders are missing. The packages are configured correctly with proper `exports` in `package.json`, but the built files need to be generated and committed to the repository.

## Current State

### @createnew/tokens Package
- **Location**: `packages/tokens/`
- **Build Script**: `npm run build` (runs: `tsc && style-dictionary build && node build.js`)
- **Expected Output**: `packages/tokens/dist/` containing:
  - `tokens.js` (TypeScript compiled)
  - `tokens.d.ts` (TypeScript definitions)
  - `tokens.css` (CSS custom properties generated by Style Dictionary + build.js)
  - `fonts/` (font files copied by build.js)
- **Package.json Exports**:
  - `"."` → `./dist/tokens.js`
  - `"./tokens.css"` → `./dist/tokens.css`
- **Current Issue**: `dist/` folder doesn't exist, so imports fail

### @createnew/ui-react Package
- **Location**: `packages/ui-react/`
- **Build Script**: `npm run build` (runs: `tsc && npm run build:css`)
- **Build CSS Script**: `npm run build:css` (runs: `node build-css.js`)
- **Expected Output**: `packages/ui-react/dist/` containing:
  - `index.js` (TypeScript compiled)
  - `index.d.ts` (TypeScript definitions)
  - `styles.css` (component styles)
- **Package.json Exports**:
  - `"."` → `./dist/index.js`
  - `"./styles.css"` → `./dist/styles.css`
- **Current Issue**: `dist/` folder doesn't exist, so imports fail

## Required Actions

### 1. Build Both Packages

Run the build scripts to generate the `dist/` folders:

```bash
# From the CNDS repo root
npm run build
```

This will:
- Build `@createnew/tokens` (generates `packages/tokens/dist/`)
- Build `@createnew/ui-react` (generates `packages/ui-react/dist/`)
- Build `@createnew/playground` (optional, for development)

### 2. Verify Build Output

Check that the following files exist:

**For @createnew/tokens:**
- `packages/tokens/dist/tokens.js`
- `packages/tokens/dist/tokens.d.ts`
- `packages/tokens/dist/tokens.css`
- `packages/tokens/dist/fonts/` (if fonts are used)

**For @createnew/ui-react:**
- `packages/ui-react/dist/index.js`
- `packages/ui-react/dist/index.d.ts`
- `packages/ui-react/dist/styles.css`

### 3. Commit dist/ Folders to Git

**Important**: The `dist/` folders must be committed to the repository so that when someone installs from GitHub, the built files are available.

Check `.gitignore` files to ensure `dist/` is NOT ignored:
- `packages/tokens/.gitignore` should NOT ignore `dist/`
- `packages/ui-react/.gitignore` should NOT ignore `dist/`

If `dist/` is in `.gitignore`, either:
- Remove it from `.gitignore`, OR
- Use `git add -f packages/tokens/dist packages/ui-react/dist` to force add

### 4. Set Up Automated Builds (Recommended)

To ensure `dist/` folders stay up-to-date, set up one of these:

#### Option A: GitHub Actions (Recommended)
Create `.github/workflows/build-on-push.yml`:

```yaml
name: Build Packages

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm ci
      - run: npm run build
      - name: Check for dist files
        run: |
          test -d packages/tokens/dist || exit 1
          test -d packages/ui-react/dist || exit 1
          test -f packages/tokens/dist/tokens.css || exit 1
          test -f packages/ui-react/dist/styles.css || exit 1
```

#### Option B: Pre-commit Hook
Add a pre-commit hook to ensure packages are built before committing:

```bash
# .husky/pre-commit or .git/hooks/pre-commit
npm run build
git add packages/*/dist
```

#### Option C: postinstall Script (Alternative)
Add to root `package.json`:

```json
{
  "scripts": {
    "postinstall": "npm run build"
  }
}
```

**Note**: This makes installs slower but ensures dist files exist. However, it requires all devDependencies to be available, which may not be ideal for consumers.

### 5. Update Documentation

Add a section to the main README explaining:
- How to install from GitHub: `npm install github:CreateNewCo/CNDS#main`
